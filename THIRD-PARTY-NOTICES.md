# Third-Party Notices for the Local Proxy Patch

The proxy patch adds `https-proxy-agent`, `agent-base`, `debug`, `ms`, and
`proxy-from-env` to the runtime bundle. Their upstream copyright notices and
MIT license terms are reproduced below. `@smithy/node-http-handler` was
already an Apache-2.0-licensed AWS SDK dependency and is now a direct dependency.
Exact versions are recorded in `package-lock.json`. This document covers the
new MIT dependencies, not an inventory of all pre-existing bundled dependencies.
